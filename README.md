# Cognevance Project 2: AI Chatbot Using NLP

A lightweight intent based chatbot built with Streamlit and classical NLP. The model converts text into TF-IDF features and predicts an intent with Logistic Regression.

## Features

- Streamlit chat interface for interactive messages
- TF-IDF text vectorization with unigrams and bigrams
- Logistic Regression intent classification
- Intent labels for greeting, goodbye, thanks, name, help, hours, mood, and fallback

## Evaluation

The latest recorded evaluation reached **73.53% accuracy on 34 test examples**. This is an observed result on the project's current small dataset, not a guarantee of performance on new messages.

The evaluation report shows **0.00 recall for the `help` intent** (two test examples), meaning the model failed to correctly identify the help examples in that split. The dataset is small, and some intent classes have very limited evaluation support. Results can vary with the data split and should be treated as an early project baseline.

## Requirements

- Python 3.9 or later
- `streamlit`
- `scikit-learn`
- `joblib`

Install dependencies from the project root:

```bash
pip install streamlit scikit-learn joblib
```

## Run

From the repository root, train the model if the saved model is not present:

```bash
python train_chatbot.py
```

Then launch the Streamlit app (adjust the filename if your app script has a different name):

```bash
streamlit run app.py
```

Keep the training data and model files in the locations expected by the scripts. Training creates `chatbot_model.pkl` when run successfully.

## Notes

This is a compact educational/demo chatbot. TF-IDF and Logistic Regression work best when the training examples represent the phrasing users are likely to type. Add and balance examples for each intent, especially `help`, then retrain and evaluate on a separate representative test set before relying on the chatbot.
